# Heartwarming Pet Care Network

这是一个温馨的宠物护理网络平台，旨在为宠物主人和护理服务提供者之间建立一个高效、便捷的沟通桥梁。通过这个平台，用户可以轻松管理宠物信息、预订护理服务、查看医疗记录等。

## 功能特点

- **用户管理**：支持管理员、兽医、寄养员等多种角色的用户管理。
- **宠物信息管理**：用户可以添加、编辑、删除宠物信息。
- **服务预订**：提供多种宠物护理服务的预订功能，包括寄养、医疗等。
- **订单管理**：用户可以查看订单状态、支付订单、取消订单等。
- **数据统计**：提供详细的业务数据统计和分析，帮助管理者更好地了解业务状况。
- **通知系统**：系统会发送重要通知给用户，确保用户不会错过任何重要信息。
- **文件上传**：支持用户上传宠物的照片和其他相关文件。

## 技术栈

- **后端**：使用Spring Boot框架，结合MyBatis进行数据库操作，Redis用于缓存管理，JWT用于身份验证。
- **前端**：使用Vue.js框架，结合Vant UI组件库，提供良好的用户体验。
- **数据库**：使用MySQL作为主要的数据库管理系统。
- **其他工具**：使用Maven进行项目依赖管理，Redis用于缓存，Nginx用于反向代理和负载均衡。

## 安装与部署

### 后端部署

1. **环境准备**：确保已经安装了Java 8或更高版本，Maven，MySQL，Redis。
2. **数据库配置**：在MySQL中创建数据库，并导入项目中的SQL文件。
3. **配置文件修改**：修改`application.yml`文件中的数据库连接信息、Redis配置等。
4. **启动项目**：使用Maven命令`mvn spring-boot:run`启动项目，或者将项目打包成JAR文件后运行。

### 前端部署

1. **环境准备**：确保已经安装了Node.js和npm。
2. **安装依赖**：在项目根目录下运行`npm install`安装依赖。
3. **启动开发服务器**：运行`npm run dev`启动开发服务器，访问`http://localhost:3000`查看应用。
4. **构建生产环境**：运行`npm run build`构建生产环境代码，生成的代码位于`dist`目录。

## 使用说明

### 用户管理

- **管理员**：可以管理所有用户、服务项目、订单等。
- **兽医**：可以查看和管理医疗记录。
- **寄养员**：可以查看和管理寄养记录。
- **普通用户**：可以添加宠物信息、预订服务、查看订单等。

### 宠物信息管理

- **添加宠物**：用户可以添加宠物的基本信息，包括宠物名称、种类、品种、性别、体重、健康状况等。
- **编辑宠物信息**：用户可以随时更新宠物的信息。
- **删除宠物信息**：用户可以删除不再需要的宠物信息。

### 服务预订

- **选择服务**：用户可以选择不同的服务项目，包括寄养、医疗等。
- **预订服务**：用户可以选择服务时间、宠物等信息后提交订单。
- **支付订单**：用户可以通过多种支付方式完成订单支付。

### 订单管理

- **查看订单**：用户可以查看所有订单的状态、支付情况等。
- **取消订单**：用户可以在订单未开始前取消订单。
- **订单详情**：用户可以查看订单的详细信息，包括服务内容、时间、价格等。

### 数据统计

- **业务统计**：提供每日、每周、每月的业务统计数据。
- **收入统计**：展示不同时间段的收入情况。
- **用户增长**：展示用户的增长趋势。

### 通知系统

- **系统通知**：系统会发送重要通知给用户，如订单状态变更、服务提醒等。
- **消息中心**：用户可以在消息中心查看所有通知，并标记为已读或未读。

### 文件上传

- **上传宠物照片**：用户可以上传宠物的照片，方便识别和管理。
- **上传其他文件**：用户可以上传与宠物相关的其他文件，如疫苗接种证明等。
